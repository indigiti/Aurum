# Position book
All exposure quantities use integer troy ounces (100 oz = 1 virtual lot). Gross = buys + sells; net = buys - sells; matched quantity per side = min(buys, sells). Pending orders are not open exposure. Server-observed bid/ask, not the browser ticker, determine floating P&L. No quote means P&L unavailable. Matched close uses oldest positions first, including partial closes, and realizes each leg at its respective fresh bid/ask in a single account transaction. It is not exchange-native close-by or netting; spread and realized losses remain. Snapshot validation rejects book changes including independently triggered stops or pending orders. Closing all positions leaves pending orders unless Flatten + cancel orders is explicitly selected. Existing risk checks still run before and after manual actions. No new runtime, storage schema or deployment configuration.
