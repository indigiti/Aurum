# Aurum V3 — chart-first visual system

Aurum's original implementation is inspired by chart-centric workstations, not an exact reproduction of another site's assets. Neutral dark/light palettes, self-hosted Inter/Manrope/IBM Plex Mono fonts, compact navigation, chart toolbar and drawing rail, responsive chart sizing, collapsible/resizable order ticket, positions/orders/history tabs, observed risk progress and mobile shortcuts. Theme, navigation density and ticket width persist locally. SMA 20/50, EMA 20, horizontal levels, fit and expanded chart modes use existing chart data. No simulated data is invented for live prices. The existing PHP execution engine, account controls, API ports and DigiOps contract remain unchanged. Advanced drawing types, multi-chart synchronization, custom scripts and server alerts are separate future feature work.
