# One-click demo

Available by default on staging/test; disabled by default in production. Override with private DEMO_ENABLED config. No user record or shared password. Starts with $100,000 virtual capital, one challenge, up to two hours per session (or earlier session garbage collection), and 300 successful order actions before reset. Demo state lives only in server PHP sessions, is excluded from registered-user administration and migration, and is cleared on exit or successful registered login. It supports simulated trades, analytics and historical backtests, using actual OKX quotes when available. Test environment alone uses a deterministic quote fixture for demo execution. No unattended demo worker, multiple challenge accounts, AI provider requests, admin access or payout requests. Missing live quotes block new simulated orders. Reset is destructive only to demo session history. No additional Cloudways or DigiOps configuration for default staging.
